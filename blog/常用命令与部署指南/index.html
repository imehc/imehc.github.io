Vercel部署分支设置、Git操作、包管理器清理、Docker启动PostgreSQL/MinIO以及SCP文件传输等快速参考指南

Vercel 部署指定分支设置方法​

Vercel 默认会部署 main 分支。如需部署其他指定分支，请按以下步骤操作：

步骤操作
1在项目完成初始部署后，进入项目主页
2点击 Settings → Environments
3找到下方的 Production 环境并点击
4在 Branch Tracking 设置中输入目标分支名
5点击 Save 保存设置

注意事项：

  • 更换分支后，需要重新推送代码到新分支才能触发新的部署
  • 设置完成后，只有指定分支的更新才会触发生产环境部署

Git常用命令​

命令说明
git checkout origin/origin-branch -- ../filepath/file.txt检出远程指定分支的文件到当前分支
git rebase --abort取消变基操作
git merge --abort取消合并操作

查看远程分支​

命令说明
git branch -r只显示远程分支(如 origin/main、origin/feature-x)
git branch -a查看所有分支(本地 + 远程),本地分支不带前缀,远程分支以 remotes/ 开头
git ls-remote直接列出远程仓库的分支和标签,无需先 fetch
git remote show origin显示远程分支与本地分支的追踪关系,以及哪些远程分支已过时
git branch -r | grep feature快速定位包含 feature 的远程分支

同步与清理远程分支​

远程分支有变动时,本地缓存可能未更新,git fetch origin 一下就行,这是正常的同步操作:

# 获取远程最新分支信息(不合并)
git fetch origin

# 清理本地已不存在的远程分支引用
git remote prune origin

# 或者 fetch 时直接清理
git fetch --prune origin

删除远程分支​

# 1. 推送空分支(最常用)
git push origin --delete 分支名
# 或简写
git push origin -d 分支名

# 2. 冒号语法(老版本兼容),含义是"将空引用推送到远程分支",效果等同于删除
git push origin :分支名

# 3. 删除远程标签(类似语法)
git push origin --delete tag 标签名

完整流程示例(同时删除远程和本地分支):

# 1. 查看远程分支
git branch -r

# 2. 删除远程分支 feature-x
git push origin --delete feature-x

# 3. 删除本地分支(删除远程分支不会自动删除本地分支)
git branch -d feature-x

# 4. 清理本地残留的远程追踪分支
git fetch --prune origin

注意事项:

情况说明
分支被保护GitHub/GitLab 等平台上若分支受保护,需先取消保护
其他人正在使用确认团队内无人基于该分支工作
本地分支还在删除远程分支不会自动删除本地分支,需手动 git branch -d 分支名

包管理器清理命令​

清理 npm、pnpm、yarn 等包管理器的缓存和未使用的包,释放磁盘空间。

npm​

命令说明
npm cache clean --force清理全局缓存(npm 缓存有自愈机制,必须加 --force)
npm cache verify校验缓存完整性并清理无效数据
npm prune移除 node_modules 中未在 package.json 声明的包

pnpm​

命令说明
pnpm store prune清理全局 store 中未被任何项目引用的包
pnpm store path查看全局 store 路径
pnpm prune移除项目 node_modules 中未被依赖的包

yarn​

命令说明
yarn cache clean清理缓存(Yarn 1 为全局缓存,Yarn 2+ 为项目本地缓存)
yarn cache clean --mirror清理全局镜像缓存(Yarn 2+)
yarn cache dir查看缓存目录(Yarn 1)

Yarn 1 没有单独的 prune 命令,执行 yarn install 时会自动移除多余的包。

bun​

命令说明
bun pm cache rm清理全局缓存
bun pm cache查看全局缓存路径

Docker常用命令​

PostgreSQL(关系型数据库)​

docker run -d
--name [容器名称]
-e POSTGRES_DB=[数据库名称]
-e POSTGRES_USER=[数据库用户]
-e POSTGRES_PASSWORD=[数据库密码]
-e POSTGRES_MAX_CONNECTIONS=[数据库最大连接数]
-e PGUSER=[默认用户]
-p 5432:5432
postgres:latest
参数说明
docker run -d后台运行容器
--name postgres-db指定容器名称
-e POSTGRES_DB=[数据库名]设置数据库名称
-e POSTGRES_USER=[用户名]设置数据库用户
-e POSTGRES_PASSWORD=[密码]设置数据库密码
-e POSTGRES_MAX_CONNECTIONS=[最大连接数]设置数据库最大连接数
-e PGUSER=[用户]设置默认用户
-p 5432:5432映射容器端口到主机端口
postgres:latest使用的镜像及版本

MinIO(对象存储服务)​

docker run -d
--name [容器名称]
-e MINIO_ROOT_USER=[MinIO根用户]
-e MINIO_ROOT_PASSWORD=[MinIO根密码]
-p 9000:9000
-p 9001:9001
bitnami/minio:2024.7.4
参数说明
docker run -d后台运行容器
--name minio-db指定容器名称
-e MINIO_ROOT_USER=[用户名]设置MinIO根用户
-e MINIO_ROOT_PASSWORD=[密码]设置MinIO根密码(至少8位)
-p 9000:9000映射API端口到主机
-p 9001:9001映射控制台端口到主机
bitnami/minio:2024.7.4使用的镜像及版本

文件传输命令​

SCP (Secure Copy Protocol)​

scp -r [源路径] [用户名]@[IP地址]:[目标路径]
参数说明
scp安全复制命令
-r递归复制整个目录
[源路径]本地要复制的文件或目录路径
[用户名]远程服务器用户名
[IP地址]远程服务器IP地址
[目标路径]程服务器上的目标路径
